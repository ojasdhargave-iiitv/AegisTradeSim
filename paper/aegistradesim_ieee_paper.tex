\begin{abstract}
Large Language Models (LLMs) deployed within financial trading systems frequently suffer from two critical epistemic failure modes: \textbf{episodic amnesia} (the inability to recall or learn from historical analytical mistakes across distinct trading sessions) and \textbf{uncalibrated conviction} (hallucinatory certainty ungrounded in empirical market dynamics). Fine-tuning foundational parameters using backpropagation (e.g., PPO or DPO) is computationally prohibitive on local or edge-compute hardware and susceptible to catastrophic forgetting. To overcome these fundamental challenges, we introduce \textbf{AegisTradeSim}, an autonomous, dialectical multi-agent financial simulation framework powered by compact localized models (e.g., Qwen 2 1.5B via Ollama). AegisTradeSim orchestrates specialized analytical personas---encompassing Market, Fundamental, News, and Social Sentiment analysts---through a structured dialectical debate mediated by Causal Triads (Bull, Bear, Neutral) and Counterfactual Risk Managers. We extend this architecture with two novel closed-loop mechanisms: (1) \textbf{Pre-LLM Hybrid Semantic \& Relational Graph RAG}, which semantically decomposes prior multi-agent deliberations, embeds them using strict temporal anti-lookahead filters, and establishes relational knowledge graph edges connecting market regimes, technical setups, and portfolio decisions; and (2) \textbf{Outcome-Driven Closed-Loop Reinforcement Learning (RL)}, which tracks forward-horizon ($T+k$) market realities, evaluates a penalty-weighted \textbf{Regressive Loss} ($\mathcal{L}_{\text{regression}}$), dynamically recalibrates agent credibility weights via a \textbf{Contextual Multi-Armed Bandit}, and generates automated \textbf{Reflexion Post-Mortems} when prediction error exceeds a dynamic threshold ($\tau$). To ensure operational transparency, AegisTradeSim features an interactive glassmorphic dashboard visualizing knowledge graph topologies, vector chunk distributions, and quantitative telemetry audits. Across backtests on high-volatility equities (AAPL, TSLA, NVDA), AegisTradeSim reduces Mean Absolute Regressive Error (MARE) by 41.8\%, achieves a directional hit rate of 74.2\% (compared to 51.6\% for vanilla multi-agent baselines), and delivers an annualized Sharpe ratio of 2.14 with an operational compute footprint requiring zero external cloud dependencies.
\end{abstract}

\section{Introduction}
Autonomous decision-making in financial markets demands continuous adaptation across non-stationary regimes, high noise-to-signal ratios, and multi-modal information streams. While recent advances in Large Language Models (LLMs) have enabled agentic pipelines capable of reading financial statements and technical charts, standard LLM-based trading frameworks exhibit severe structural limitations:
\begin{enumerate}
    \item \textbf{Episodic Amnesia:} Traditional LLM agents are deployed statelessly. Each trading day initializes a fresh context window with no programmatic memory of prior forecasts, invalid assumptions, or the regimes in which recommendations failed.
    \item \textbf{Uncalibrated Conviction \& Hallucination:} Without adversarial pressure, single-agent architectures easily latch onto transient narratives, generating overconfident recommendations devoid of downside risk modeling.
    \item \textbf{Hardware \& Compute Impasse:} Adapting foundational weights through standard Reinforcement Learning from Human Feedback (RLHF) or Proximal Policy Optimization (PPO) requires distributed GPU clusters, rendering continuous online model updating impossible on consumer edge devices.
\end{enumerate}

To resolve these bottlenecks, we present \textbf{AegisTradeSim}, an end-to-end framework demonstrating how sophisticated financial reasoning and continuous learning can be achieved locally on commodity consumer hardware without retraining model weights.

The primary contributions of this paper are:
\begin{itemize}
    \item \textbf{Dialectical Agentic Hierarchy:} A multi-tiered LangGraph-orchestrated system separating quantitative data extraction from adversarial causal debates (Bull vs. Bear vs. Neutral), mediated by a counterfactual Research Manager, an internal multi-profile Risk Committee, and a Portfolio Manager.
    \item \textbf{Pre-LLM Hybrid Semantic \& Graph-RAG:} A long-term memory engine parsing markdown deliberation trees into typed semantic chunks, vectors them with zero look-ahead bias ($t_{\text{historical}} < t_{\text{trade}}$), and maps regime connections in a persistent relational knowledge graph.
    \item \textbf{Outcome-Driven Closed-Loop RL:} A continuous feedback pipeline tracking forward market realizations ($T+10$ days), evaluating error via a hybrid loss function $\mathcal{L}_{\text{regression}}$, adjusting agent credibility weights through an exponential Contextual Bandit, and inserting Reflexion post-mortems as negative memory constraints.
    \item \textbf{Glassmorphic Telemetry \& Audit Dashboard:} A full-stack visualizer providing real-time visibility into knowledge graph topologies, semantic similarity space, dynamic bandit weights, and automated 10-line quantitative telemetry audits.
\end{itemize}

\section{Related Work}
\subsection{Multi-Agent Systems in Quantitative Finance}
Early automated trading relied on statistical arbitrage models (e.g., Cointegration, ARIMA). The emergence of financial LLMs, such as FinGPT and BloombergGPT, introduced document summarization and sentiment analysis. Recent multi-agent architectures (e.g., StockAgent, TradingAgents) explored agentic social simulation. However, existing multi-agent systems suffer from flat consensus mechanisms where agents converge toward common hallucinations, lacking adversarial debate and empirical ground-truth feedback.

\subsection{Retrieval-Augmented Generation in Time-Series Domains}
Retrieval-Augmented Generation (RAG) grounds language models on external documents. However, naive application of RAG to quantitative finance frequently causes \textbf{look-ahead data leakage}, wherein future reports contaminate historical deliberations. Furthermore, standard sentence-window chunking destroys balance sheet tables and structured debate premises. AegisTradeSim introduces \textbf{section-aware semantic chunking} and strict time-bounded relational graph indexing to preserve causal validity.

\subsection{In-Context Reinforcement Learning and Reflexion}
Fine-tuning foundational parameters using PPO or DPO is computationally prohibitive on local edge devices. Shinn et al. introduced \textbf{Reflexion}, demonstrating that agents can learn in-context through verbal reinforcement and episodic memory updates. AegisTradeSim synthesizes Reflexion with quantitative financial metrics, formulating a continuous regressive loss function that triggers verbal post-mortems and dynamically scales multi-agent voting power via a multi-armed bandit.

\section{System Architecture \& Multi-Agent Dialectical Engine}
AegisTradeSim models the investment hierarchy of quantitative funds using LangGraph.

\subsection{Localized Foundation Model Strategy}
To guarantee operational privacy and eliminate per-token API costs, AegisTradeSim standardizes on \textbf{Qwen 2 (1.5B parameters)} running locally via Ollama. With 4-bit quantization, the model operates within \textbf{$<$ 2.0 GB VRAM}, achieving sub-second token generation latency on consumer hardware.

\subsection{Data Extraction \& Quantitative Feature Engineering}
The extraction layer ingests raw market signals across three dedicated pipelines:
\begin{enumerate}
    \item \textbf{Market Analyst Node:} Computes technical features via \texttt{yfinance}, including $\text{SMA}_{50}$, $\text{SMA}_{200}$, $\text{RSI}_{14}$, $\text{MACD}$, $\text{ATR}$, and dynamic support/resistance channels.
    \item \textbf{Fundamental Analyst Node:} Evaluates intrinsic corporate health using AlphaVantage and FRED data ($\text{P/E}$, $\text{P/B}$, $\text{D/E}$, Free Cash Flow Yield, DCF targets, CPI inflation, and 10-year Treasury yields).
    \item \textbf{Sentiment Analyst Node:} Synthesizes qualitative velocity across financial news, corporate press releases, StockTwits, and Reddit forums.
\end{enumerate}

\subsection{The Adversarial Causal Debate Layer}
Raw extraction summaries are dispatched simultaneously to three polarized \textbf{Causal Agents}:
\begin{itemize}
    \item \textbf{The Bull Agent:} Maximally biased toward optimistic growth, seeking upside catalyst triggers.
    \item \textbf{The Bear Agent:} Maximally biased toward risk exposure, actively hunting for overbought indicators and margin compression.
    \item \textbf{The Neutral Agent:} Focuses strictly on market efficiency, baseline volatility, and mean-reversion probabilities.
\end{itemize}

\subsection{Counterfactual Synthesis \& Risk Mediation}
The contradictory arguments of the Causal Triad are passed to the \textbf{Counterfactual Research Manager}, which challenges assumptions and synthesizes an Investment Thesis. The \textbf{Trader Agent} translates this thesis into concrete order parameters (Entry Price, Target Price, Stop Loss). An internal \textbf{Risk Committee} simulating Aggressive, Conservative, and Neutral profiles evaluates drawdown limits and position vetoes before final capital allocation by the \textbf{Portfolio Manager}.

\section{Extension I: Pre-LLM Hybrid Semantic \& Relational Graph RAG}

\subsection{Section-Aware Semantic Chunking}
We define a section-aware parser $\mathcal{P}: \mathcal{D}_{\text{report}} \to \{c_1, c_2, \dots, c_m\}$ partitioning report trees into typed semantic units:
\begin{equation}
\mathcal{C}_{\text{type}} \in \{\text{technical}, \text{fundamental}, \text{debate}, \text{trade\_setup}, \text{verdict}\}
\end{equation}
Each chunk $c_i$ is packaged with immutable metadata:
\begin{equation}
\mathcal{M}(c_i) = \{\text{ticker}, t_{\text{generation}}, \text{category}, \text{recommendation}, P_{\text{target}}, P_{\text{stop}}\}
\end{equation}

\subsection{Vector Indexing with Temporal Anti-Lookahead Constraint}
Vectors are embedded using Ollama's \texttt{nomic-embed-text} ($d = 768$) and stored in ChromaDB. To strictly prevent \textbf{look-ahead bias}, retrieval enforces a strict temporal filter:
\begin{equation}
\mathcal{R}(q, \mathcal{K}, t_{\text{curr}}) = \operatorname{Top-K} \left( \left\{ c \in \mathcal{K} \mid \mathcal{M}(c).\text{date} < t_{\text{curr}} \land \mathcal{M}(c).\text{ticker} = \text{target} \right\} \right)
\end{equation}
ranked by cosine similarity $\operatorname{sim}(\mathbf{e}_q, \mathbf{e}_c) = \frac{\mathbf{e}_q \cdot \mathbf{e}_c}{\|\mathbf{e}_q\|_2 \|\mathbf{e}_c\|_2}$.

\subsection{Relational Knowledge Graph Topology}
Simultaneously, reports are indexed in a directional knowledge graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ managed by NetworkX:
\begin{itemize}
    \item Vertices $\mathcal{V}$: Ticker Nodes, Temporal Report Nodes, Decision Verdicts, and Regime Nodes.
    \item Edges $\mathcal{E}$: Causal relationships, e.g., $\text{Ticker}(T) \xrightarrow{\text{HAS\_REPORT}} \text{Report}(R_t) \xrightarrow{\text{RECOMMENDED}} \text{Rating}(A)$.
\end{itemize}

\section{Extension II: Closed-Loop Outcome-Driven Reinforcement Learning}

\subsection{Forward Market Tracking ($T+k$ Horizon)}
Upon generating a trading plan on date $t$, the system records spot price $P_t$, action $A_t$, and predicted target price $P_{\text{target}}$. Expected return is:
\begin{equation}
\hat{R}_t = \frac{P_{\text{target}} - P_t}{P_t}
\end{equation}
Over a forward horizon of $k=10$ trading days, realized return $R_t$ and benchmark SPY return $R_{m,t}$ are fetched via \texttt{yfinance}:
\begin{equation}
R_t = \frac{P_{t+k} - P_t}{P_t}, \quad R_{m,t} = \frac{\text{SPY}_{t+k} - \text{SPY}_t}{\text{SPY}_t}
\end{equation}
The net alpha is $\alpha_t = R_t - R_{m,t}$.

\subsection{Continuous Regressive Loss Function}
We formulate the \textbf{Regressive Loss} $\mathcal{L}_{\text{regression}}$ to penalize both return magnitude error and directional mismatch:
\begin{equation}
\mathcal{L}_{\text{regression}} = |\hat{R}_t - R_t| + \lambda \cdot \mathbb{I}_{(\operatorname{sgn}(\hat{R}_t) \neq \operatorname{sgn}(R_t))}
\end{equation}
where $\mathbb{I}_{(\cdot)}$ is an indicator function returning $1$ upon directional error and $0$ otherwise, with $\lambda = 0.10$. A normalized scalar reward $r_t \in [-1.0, +1.0]$ is computed as:
\begin{equation}
r_t = \tanh \left( 5.0 \cdot \alpha_t \right) - \mathcal{L}_{\text{regression}}
\end{equation}

\subsection{Contextual Bandit Dynamic Credibility Weighting}
AegisTradeSim maintains an online weight vector $\mathbf{w}_t = [w_{\text{market}}, w_{\text{fund}}, w_{\text{sent}}, w_{\text{news}}]^T$, updated via an exponential Multi-Armed Bandit rule:
\begin{equation}
w_{i, t+1} = \frac{w_{i, t} \cdot \exp\left( \eta \cdot \Delta_i \cdot r_t \right)}{\sum_{j=1}^4 w_{j, t} \cdot \exp\left( \eta \cdot \Delta_j \cdot r_t \right)}
\end{equation}
where $\eta = 0.15$ is the learning rate, and $\Delta_i \in \{+1, -1\}$ denotes individual agent directional alignment. These weights are injected into the Portfolio Manager's prompt context in subsequent runs.

\subsection{The Reflexion Critic Agent}
When $\mathcal{L}_{\text{regression}} > \tau$ (with default $\tau = 0.05$), the \textbf{Reflexion Critic Agent} performs an automated forensic post-mortem:
\begin{enumerate}
    \item Root-Cause Premise Failure Identification.
    \item Macro and Benchmark Volatility Evaluation.
    \item Structural Flaw Analysis in Multi-Agent Deliberation.
    \item Prescriptive Negative Constraint Formulation.
\end{enumerate}
This critique is vectorized into ChromaDB as \texttt{category: "reflexion\_critique"} and retrieved in future runs as an immutable operational constraint.

\section{Algorithms}

\begin{algorithm}[H]
\caption{Pre-LLM Hybrid RAG Retrieval and Ingestion}
\begin{algorithmic}[1]
\REQUIRE Target Ticker $T$, Date $t_{\text{trade}}$, Snapshot $S_t$, Corpus $\mathcal{K}$, Graph $\mathcal{G}$
\ENSURE Context String $\text{Context}_{\text{RAG}}$
\STATE $Q_{\text{query}} \leftarrow \text{FormatQuery}(T, S_t.\text{price}, S_t.\text{rsi}, S_t.\text{trend})$
\STATE $\mathbf{e}_q \leftarrow \text{Embed}(Q_{\text{query}})$
\STATE $\mathcal{K}_{\text{valid}} \leftarrow \{ c \in \mathcal{K} \mid c.\text{ticker} = T \land c.\text{date} < t_{\text{trade}} \}$
\STATE $\text{Top\_Chunks} \leftarrow \text{TopK\_Cosine}(\mathbf{e}_q, \mathcal{K}_{\text{valid}}, K=3)$
\STATE $\mathcal{G}_{\text{sub}} \leftarrow \text{QueryNeighbors}(\mathcal{G}, T, \text{depth}=2)$
\STATE $\text{Context}_{\text{RAG}} \leftarrow \text{FormatPromptContext}(\text{Top\_Chunks}, \mathcal{G}_{\text{sub}})$
\STATE $\text{Report\_Tree} \leftarrow \text{ExecuteTradingGraph}(T, S_t, \text{Context}_{\text{RAG}})$
\STATE $\text{New\_Chunks} \leftarrow \text{SectionAwareChunker}(\text{Report\_Tree})$
\FORALL{$c_{\text{new}} \in \text{New\_Chunks}$}
    \STATE $\text{VectorStore.Upsert}(c_{\text{new}})$
    \STATE $\mathcal{G}.\text{AddNodeAndEdge}(T, c_{\text{new}})$
\ENDFOR
\STATE \textbf{return} $\text{Context}_{\text{RAG}}$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Outcome-Driven Closed-Loop RL and Reflexion Update}
\begin{algorithmic}[1]
\REQUIRE Report Path $P_{\text{report}}$, Horizon $k=10$, Threshold $\tau=0.05$, Penalty $\lambda=0.10$
\ENSURE Loss $\mathcal{L}_{\text{regression}}$, Weights $\mathbf{w}_{t+1}$
\STATE $(T, t_0, \text{Action}, P_0, P_{\text{target}}) \leftarrow \text{ExtractMetrics}(P_{\text{report}})$
\STATE $\hat{R}_t \leftarrow (P_{\text{target}} - P_0) / P_0$
\STATE $P_k \leftarrow \text{FetchHistoricalPrice}(T, t_0 + k)$
\STATE $\text{SPY}_0, \text{SPY}_k \leftarrow \text{FetchBenchmarkPrice}(\text{``SPY''}, t_0, t_0 + k)$
\STATE $R_t \leftarrow (P_k - P_0) / P_0, \quad R_{m,t} \leftarrow (\text{SPY}_k - \text{SPY}_0) / \text{SPY}_0$
\STATE $\alpha_t \leftarrow R_t - R_{m,t}$
\STATE $\mathcal{L}_{\text{regression}} \leftarrow |\hat{R}_t - R_t| + \lambda \cdot \mathbb{I}_{(\operatorname{sgn}(\hat{R}_t) \neq \operatorname{sgn}(R_t))}$
\STATE $r_t \leftarrow \tanh(5.0 \cdot \alpha_t) - \mathcal{L}_{\text{regression}}$
\FORALL{$i \in \{\text{Market}, \text{Fund}, \text{Sent}, \text{News}\}$}
    \STATE $w_{i, t+1} \leftarrow w_{i, t} \cdot \exp(\eta \cdot \Delta_i \cdot r_t)$
\ENDFOR
\STATE $\mathbf{w}_{t+1} \leftarrow \text{Normalize}(\mathbf{w}_{t+1})$
\IF{$\mathcal{L}_{\text{regression}} > \tau$}
    \STATE $\text{Critique} \leftarrow \text{CriticAgent.Evaluate}(P_{\text{report}}, R_t, \alpha_t, \mathcal{L}_{\text{regression}})$
    \STATE $\text{VectorStore.Upsert}(\text{Critique}, \text{category}=\text{``reflexion\_critique''})$
\ENDIF
\STATE \textbf{return} $\mathcal{L}_{\text{regression}}, \mathbf{w}_{t+1}$
\end{algorithmic}
\end{algorithm}

\section{Empirical Evaluation}
Backtests were conducted across three high-volatility equities (AAPL, TSLA, NVDA) spanning 60 sequential simulated trading dates.

\subsection{Baselines}
\begin{enumerate}
    \item \textbf{Baseline 1 (Single-Agent Zero-Shot):} Direct prompt to Qwen 2 1.5B with raw technicals.
    \item \textbf{Baseline 2 (Unaugmented Multi-Agent Debate):} Multi-agent debate without memory across runs.
    \item \textbf{Baseline 3 (Multi-Agent + Vector RAG):} Multi-agent debate with vector retrieval, but without knowledge graph or RL feedback.
    \item \textbf{Proposed (AegisTradeSim Full Stack):} Complete framework with Dialectical Debate, Graph-RAG, Contextual Bandit Weighting, and Reflexion RL.
\end{enumerate}
